# Netflix Stock Data Analysis

This project analyzes Netflix stock market data using Python and popular data analysis libraries such as Pandas, NumPy, Matplotlib, Seaborn, and Plotly.

## 📌 Project Overview

The notebook performs:

- Data loading and cleaning
- Exploratory Data Analysis (EDA)
- Stock price visualization
- Trend analysis
- Interactive charts using Plotly

## 📂 Files Included

- `netflix.ipynb` → Main analysis notebook
- `NFLX.csv` → Netflix stock dataset
- `netflix_titles.csv` → Netflix titles dataset
- `Iphonedells.ipynb` → Additional analysis notebook
- `apple_products.csv` → Apple products dataset
